# راهرو — مسیریاب مترو تهران (نسخه اندروید قابل نصب)

این پروژه یک وب‌اپلیکیشن پیش‌رونده (PWA) است؛ روی گوشی اندرویدی با Chrome باز می‌شود و از منوی مرورگر می‌توان آن را با گزینه Install app / Add to Home screen نصب کرد.

## اجرای سریع
1. فایل ZIP را استخراج کنید.
2. پوشه را روی یک هاست استاتیک با HTTPS منتشر کنید (مثلاً GitHub Pages یا Netlify).
3. نشانی سایت را در Chrome اندروید باز کنید.
4. منوی سه‌نقطه ← Install app یا Add to Home screen.

برای تست روی کامپیوتر می‌توانید از داخل پوشه با یک سرور محلی اجرا کنید؛ بازکردن مستقیم فایل به‌تنهایی Service Worker را فعال نمی‌کند.

## قابلیت‌ها
- انتخاب مبدأ و مقصد فارسی
- محاسبه مسیر با الگوریتم Dijkstra
- لحاظ کردن تعویض خط
- نمایش مرحله‌ای ایستگاه‌ها و نمای شماتیک مسیر
- تخمین زمان سفر، انتظار و تعویض

## محدودیت مهم نسخه آزمایشی
- داده‌های این نمونه برای خطوط ۱ تا ۴ است و برای انتشار عمومی باید با آخرین نقشه و فهرست رسمی ایستگاه‌ها تطبیق داده شود.
- نام‌ها و اتصال‌ها در این نمونه ممکن است کامل یا کاملاً منطبق با شبکه فعلی نباشند.
- زمان حرکت قطار، انتظار و رسیدن زنده نیست؛ از فرض‌های نمونه (۲.۵ دقیقه بین ایستگاه‌ها، ۴ دقیقه تعویض، فاصله حرکت ۵ یا ۱۰ دقیقه) استفاده می‌شود.
- فونت Vazirmatn در صورت دسترسی به اینترنت از Google Fonts بارگیری می‌شود؛ در نبود اینترنت فونت جایگزین استفاده می‌شود.

این پروژه APK آماده نیست؛ PWA است و پس از میزبانی HTTPS روی اندروید به شکل اپ مستقل نصب می‌شود.
